# Affiliate Popup
## Changelog/Updates
### Flyicon-v2

Displays dynamic banners/URLs, allowing users to **directly provide the parameters** `window.pUrls` and `window.pBanners`.

#### Usage

```bash
window.pUrls = ['https://example.com/page1', 'https://example.com/page2'];
window.pBanners = ['https://example.com/banner1.png', 'https://example.com/banner2.png'];
